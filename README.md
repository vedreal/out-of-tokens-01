Entry for the [make.fun bounty "Out of Tokens, Mid-Sentence"](https://make.fun/bounty/u-kiencx-out-of-tokens-mid-sentence-00f60233): the funniest one-line error message an AI agent shows when it runs out of tokens mid-sentence.

`main.py` writes ten fresh candidate lines, scores each against the judge's published criteria (humour first, freshness second, flat error-message tone that turns into the joke, self-contained, tight wording), and writes the highest-scoring line to `/output/entry.txt`.

Run it:

```sh
python3 main.py
```
